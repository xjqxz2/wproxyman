# WProxyman

一款跨平台（Windows / macOS / Linux）的 **HTTP / HTTPS 抓包调试代理工具**。
界面与交互参考 Proxyman 设计，支持 MITM 解密、HTTP/2、WebSocket 帧捕获，
以及 Map Local、断点、脚本等常用调试工具，帮助开发者查看、分析、修改应用流量。

---

## ✨ 功能特性

| 能力 | 说明 |
|---|---|
| 🔓 **HTTPS MITM 解密** | 本地 CA 动态签发域名证书，一键安装信任；证书未信任时自动降级为隧道，保证流量不中断 |
| ⚡ **HTTP/2 支持** | 完整解密多路复用流量，与 HTTP/1.1 一并呈现 |
| 🔌 **WebSocket 捕获** | 帧级双向中继 + 消息记录（文本/二进制/控制帧） |
| 🧰 **调试工具集** | Map Local、Map Remote、Block List、Allow List、断点（可编辑请求/响应）、脚本引擎、网络限速、Rules、外部代理、No Caching、Compose、Repeater、Diff |
| 📦 **内容查看** | JSON / XML 自动格式化、图片预览、二进制 hex 视图、素材一键下载保存 |
| 🔍 **搜索与过滤** | 十万级流量虚拟滚动不卡顿、按域名/方法/状态过滤、全文搜索 |
| 💾 **会话管理** | 会话保存/打开、HAR 导入/导出、cURL 导入、代码生成（cURL / Node-fetch / Postman） |
| 🌐 **国际化** | 简体中文 / English，启动跟随系统语言，设置内可手动切换 |

## 🚀 快速开始

1. 从 [Releases](https://github.com/xjqxz2/wproxyman/releases) 下载对应平台的安装包（Windows `.exe` / macOS `.dmg` / Linux `.AppImage`）；
2. 启动应用 —— **自动开启抓包代理并接管系统代理**；
3. 浏览器刷新页面，流量即出现在列表中。

> 抓包期间浏览器会自动禁用 HTTP/3（QUIC 无法走 HTTP 代理），所有流量以
> HTTP/1.1 / HTTP/2 呈现并完整解密——这是行业标准行为（Charles/Proxyman 相同）。

### macOS 首次打开

应用未通过 Apple 公证，macOS Gatekeeper 会提示"无法验证开发者"。任选其一：

1. 右键（或按住 Control）点击 `WProxyman.app` → 选择**打开**；
2. 终端执行：`xattr -d com.apple.quarantine /Applications/WProxyman.app`；
3. 系统设置 → 隐私与安全性 → **仍要打开**。

## 🔒 配置 HTTPS 解密

1. 点击工具栏 **设置 ⚙** → **SSL Proxying**；
2. 点击 **Install Certificate** 安装本地 CA（Windows 静默安装；macOS / Linux 按系统提示完成授权）；
3. 安装后自动开始解密 HTTPS 流量。

- **默认对所有域名开启**解密，也可在设置中对指定域名单独开关；
- 证书一旦不受信任（如被系统移除），对应域名自动降级为隧道直通，**不会导致流量中断**；
- 若证书安装后状态未刷新，点击状态栏的证书提示可重新检测。

## 🖥 界面速览

- **工具栏**：开始/停止抓包、清空列表、全局 SSL 开关、搜索、设置；
- **来源侧栏**：按设备、域名、收藏、已保存等维度筛选流量；
- **流量列表**：方法、域名、路径、状态码、大小、耗时、时间一目了然；右键可复制 cURL / Node-fetch 代码、置顶、删除；
- **详情面板**：点击任意流量查看 **概览 / 请求 / 响应 / WebSocket** 四个标签页；请求与响应均支持 Headers、格式化正文、Raw 三种视图；
- **状态栏**：代理运行状态与端口、系统代理开关、流量计数、证书状态。

### 查看与下载内容

- **JSON / XML** 自动格式化，正文按内容类型智能展示；
- **图片 / 音频 / PDF** 等素材类响应直接预览，点击 **Save to file** 一键保存；
- 二进制内容以 **hex 视图**呈现。

## 🧰 调试工具

工具规则均**即时生效**：修改任意配置后无需重启即可应用。

| 工具 | 作用 |
|---|---|
| **Map Local** | 将匹配的请求替换为本地文件或内联文本（自动推断 Content-Type，可自定义状态码/响应头） |
| **Map Remote** | 将匹配请求转发到指定的目标 URL |
| **Block List** | 拦截（阻断）匹配的请求 |
| **Allow List** | 仅放行匹配的请求，其余一律阻断 |
| **Breakpoints** | 在请求/响应阶段暂停流量，编辑 Headers 与正文后执行或取消 |
| **Scripting** | 运行 JavaScript 脚本修改请求/响应（onRequest / onResponse 两个阶段，支持取消请求与运行日志） |
| **Network Conditions** | 模拟弱网：下载/上传限速、延迟、丢包（内置常用预设档） |
| **Rules** | 增删改请求头/响应头、替换正文、重定向，按请求/响应阶段生效 |
| **External Proxy** | 将流量转发到上游代理（如 Burp Suite / Fiddler），支持代理认证与绕过域名 |
| **No Caching** | 移除缓存相关头，强制获取最新内容 |
| **Compose** | 手动构造请求并发送 |
| **Repeater** | 选中流量重放请求，支持修改后重发 |
| **Diff** | 对比两条流量 |

## 💾 会话与导出

- **保存 / 打开会话**：将当前全部流量保存为 `.wpx` 会话文件，随时恢复；
- **HAR 导入 / 导出**：与 Charles、Fiddler 等工具互转流量数据；
- **cURL 导入**：粘贴一段 cURL 命令自动解析为请求，便于快速构造 Compose 请求；
- **代码生成**：任意流量一键生成 **cURL / Node-fetch / Postman** 代码片段，便于复现与分享。

---

## 📱 手机等设备抓包

1. 打开设置 → **Devices**，查看本机局域网 IP；
2. 让手机连接同一 Wi-Fi，将代理指向 `电脑IP:代理端口`；
3. 手机访问 HTTPS 网站时安装并信任抓包证书（首次访问会有证书提示，安装 CA 后即可解密）。

## ⚙️ 设置

- **Proxy**：代理端口（默认自动选择）、启动时自动开启代理、系统代理开关；
- **SSL Proxying**：全局解密开关、按域名开关、证书安装/移除/查看；
- **Capture**：请求/响应体捕获大小上限（超大正文溢出部分不截断上游传输）；
- **Appearance**：深色 / 浅色主题、界面语言（中文 / English）。
